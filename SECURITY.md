# Security Policy

## Reporting

Do not disclose a suspected vulnerability in a public issue. Use the
repository's private security-advisory channel when available, or contact the
maintainers through the repository's private support route with a minimal
reproduction and affected revision.

Do not include secrets, personal data, proprietary assets, or private protocol
captures in a report.

## Supported Revisions

Security fixes are assessed against the latest committed revision and the
default feature set. Optional proprietary SDKs and local user data are outside
the default artifact boundary.
